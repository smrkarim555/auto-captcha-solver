🚀 GitHub-এ আপলোড করার ডেটা

ইউজার যুক্ত করার পর নিচের বাটনে ক্লিক করে licenses.json ফাইলটি ডাউনলোড বা কপি করে আপনার GitHub রিপোজিটরিতে পেস্ট করুন।

👥 ব্যবহারকারীদের তালিকা (Registered Devices)
নাম ডিভাইস আইডি মেয়াদ শেষ বাকি দিন স্ট্যাটাস অ্যাকশন
💡 GitHub-এর সাথে কীভাবে কানেক্ট করবেন:
  1. উপরে "Download licenses.json" বাটনে চাপ দিন।
  2. ফাইলটি আপনার গিটহাব রিপোজিটরির মেইন ব্রাঞ্চে আপলোড / পুশ করুন।
  3. গিটহাব থেকে Raw লিংকটি কপি করুন (যেমন: https://raw.githubusercontent.com/username/repo/main/licenses.json)।
  4. এক্সটেনশনের সেটিংসে এই লিংকটি দিয়ে দিন। এক্সটেনশন নিজে থেকেই চেক করে ইউজারকে একটিভ বা ব্লক করবে!
