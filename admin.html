💡 How to Connect with GitHub:
  1. Click "Download licenses.json" above (or copy JSON).
  2. Upload / push the file to the main branch of your GitHub repository.
  3. Click on licenses.json on GitHub and click Raw to get the link (e.g. https://raw.githubusercontent.com/username/repo/main/licenses.json).
  4. Paste that Raw URL into the Extension popup settings. The extension will automatically validate and control user access directly from GitHub!
